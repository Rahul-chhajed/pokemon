# Pokémon Project

## Description
This is a Pokémon project where I have built a drum that plays sounds based on some of my favorite Pokémon's voices. The project allows users to interact with a web-based interface, where they can play sounds by clicking on buttons corresponding to different Pokémon.

Check out the project here: [Pokémon Project](https://github.com/Rahul-chhajed/pokemon)

## Technologies Used
- **Frontend:** HTML, CSS, JavaScript

## Features
- **Interactive Drum Pads:** Each Pokémon button represents a unique sound from one of my favorite Pokémon.
- **Responsive Design:** The interface adjusts well to both desktop and mobile screens.
- **User-Friendly Interface:** Simple and engaging interface to play Pokémon sounds with a click.
